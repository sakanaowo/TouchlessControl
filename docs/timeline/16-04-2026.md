## Thay đổi chi tiết

### T3.1 — app.py: `--model gru` flag + GRU pipeline wiring

- **Imports**: Thêm `SequenceBuffer`, `Debouncer`, `SequenceCollector`, `TemporalClassifier`
- **Args**: `--model gru|mlp` (default `gru`), `--collect-mode single|sequence` (default `single`)
- **Model init**: Conditional — GRU mode init SequenceBuffer + TemporalClassifier + Debouncer; MLP mode init KeyPointClassifierV2 + GestureStateMachine
- **Label loading**: GRU loads `temporal_classifier_label.csv`; MLP loads `keypoint_classifier_v2_label.csv`
- **Main loop**:
  - GRU: `seq_buffer.push(features)` → `temporal_classifier(window)` → debouncer → ActionMapper
  - MLP: `keypoint_classifier(features)` → GestureStateMachine → ActionMapper (unchanged)
  - pointer_move(1) và scroll_mode(4) vẫn bypass debouncer/SM cho cả 2 mode
- **No-hand**: GRU → `debouncer.update_no_hand()`; MLP → `gesture_sm.update_no_hand()`

### T3.2 — CollectionManager: sequence mode

- `on_frame()`: delegate `add_frame(features)` thay vì buffer CSV
- `_finish()`: gọi `stop_recording()` → lấy số sequences, reload class_counts từ NPZ
- `cancel()`: gọi `cancel_recording()`
- `_load_existing_counts()`: load từ NPZ thay vì CSV khi sequence mode

### 18:20 — Fix 10fps → 30fps performance

**Vấn đề:** App chỉ chạy quanh 10fps dù camera hỗ trợ MJPG 720p ở 30fps.

**Nguyên nhân:** Trong loop còn các điểm gây overhead không cần thiết như `waitKeyEx(10)`, tạo bản sao ảnh sâu và log TF/TFLite quá nhiều khi khởi động.

**Hành động:**

- Giảm UI polling từ 10ms xuống 1ms.
- Đổi `copy.deepcopy(image)` sang `image.copy()`.
- Tắt bớt noise từ TensorFlow, oneDNN và CUDA để terminal gọn hơn khi chạy.

**Kết quả:** Vòng lặp hiển thị mượt hơn, FPS tăng ổn định hơn trên webcam thực tế. Test suite vẫn giữ nguyên 182/182 pass.

### 18:35 — Fix root cause FPS low-light

**Vấn đề:** Trong điều kiện ánh sáng thấp, camera tự tụt xuống khoảng 10fps dù đã đặt MJPG.

**Nguyên nhân:** Driver V4L2 tự bật `exposure_dynamic_framerate`, làm thời gian `cap.read()` tăng mạnh khi auto exposure kéo dài.

**Hành động:**

- Ép backend camera dùng V4L2 rõ ràng.
- Gọi `v4l2-ctl` để tắt `exposure_dynamic_framerate=0` ngay khi mở camera.
- Ghi nhận lại constraint này vào hướng dẫn dự án.

**Kết quả:** Root cause đã được khóa lại ở mức code và tài liệu; thời gian đọc frame giảm về mức phù hợp cho realtime control.
