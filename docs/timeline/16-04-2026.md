# 16-04-2026 — Phase 3: Integration GRU pipeline vào app.py

## Tổng quan

Phase 3 hoàn thành: Tích hợp GRU-64 temporal classifier vào app.py với dual-mode support (GRU/MLP).

## Thay đổi chi tiết

### T3.1 — app.py: `--model gru` flag + GRU pipeline wiring

- **Imports**: Thêm `SequenceBuffer`, `Debouncer`, `SequenceCollector`, `TemporalClassifier`
- **Args**: `--model gru|mlp` (default `gru`), `--collect-mode single|sequence` (default `single`)
- **Model init**: Conditional — GRU mode init SequenceBuffer + TemporalClassifier + Debouncer; MLP mode init KeyPointClassifierV2 + GestureStateMachine
- **Label loading**: GRU loads `temporal_classifier_label.csv`; MLP loads `keypoint_classifier_v2_label.csv`
- **Main loop**:
  - GRU: `seq_buffer.push(features)` → `temporal_classifier(window)` → debouncer → ActionMapper
  - MLP: `keypoint_classifier(features)` → GestureStateMachine → ActionMapper (unchanged)
  - pointer_move(1) và scroll_mode(4) vẫn bypass debouncer/SM cho cả 2 mode
- **No-hand**: GRU → `debouncer.update_no_hand()`; MLP → `gesture_sm.update_no_hand()`

### T3.2 — CollectionManager: sequence mode

- `CollectionManager.__init__()` nhận `sequence_collector: Optional[SequenceCollector]`
- `start_session()`: khi có seq_collector → gọi `start_recording(class_id)`
- `on_frame()`: delegate `add_frame(features)` thay vì buffer CSV
- `_finish()`: gọi `stop_recording()` → lấy số sequences, reload class_counts từ NPZ
- `cancel()`: gọi `cancel_recording()`
- `_load_existing_counts()`: load từ NPZ thay vì CSV khi sequence mode

### T3.3 — Package exports

- `utils/__init__.py`: +SequenceBuffer, Debouncer, SequenceCollector
- `model/__init__.py`: +TemporalClassifier

## Quyết định thiết kế

- **Default `--model gru`**: GRU là target chính, MLP chỉ là fallback
- **Default `--collect-mode single`**: Giữ CSV collection mặc định để backward compatible
