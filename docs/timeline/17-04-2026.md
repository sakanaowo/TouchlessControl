### 15:42 — Design scalable gesture system từ đầu

**Vấn đề:** Hệ thống hiện tại hardcode 5 gesture classes, gắn chặt pose ↔ action. Click fire liên tục (Debouncer bug). Không scale lên 20+ classes.

**Nguyên nhân:** User yêu cầu redesign toàn diện: scalable classes, đánh giá model capacity, rethink gesture semantics theo bản chất vật lý, redesign data collection cho one-shot vs continuous.

**Hành động:**

- Step-back analysis: xác định 3 tầng tách biệt (Pose Recognition → Event Engine → Action Mapping)
- Định nghĩa gesture taxonomy 12 classes theo hình dạng vật lý (index_point, pinch, fist...) thay vì action
- Đánh giá GRU-64 capacity: đủ ~10-12 classes, đề xuất GRU-128 (~87K params, ~0.15ms) cho 20-25 classes
- Thiết kế action_type system: one_shot (lockout), hold (start/end), continuous (per-frame), repeat, toggle
- Giải pháp click liên tục: deactivation_frames buffer + per-gesture lockout timer
- Redesign collection: sustained mode (static holds), one-shot mode (lặp nhanh), null variation
- Migration plan 4 phases: fix bug → rename+config → GRU-128 expand → 20+ classes
